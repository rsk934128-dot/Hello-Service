## 📖 সারসংক্ষেপ (Overview)

**NoorLink (নূরলিংক)** হলো ডিস্ট্রিবিউটেড মাইক্রোসার্ভিস, এজ ডিভাইস এবং IoT নোডসমূহের রিয়েল-টাইম পরিচালনা, মনিটরিং এবং নিরাপদ কানেক্টিভিটির জন্য একটি সর্বাধুনিক প্ল্যাটফর্ম। এটি সম্পূর্ণ হ্যান্ডশেক প্রোটোকল, স্বয়ংক্রিয় নোড আবিষ্কার, লাইভ পিং-পং হার্টবিট, JWT ডিভাইস অথেনটিকেশন, Recharts-ভিত্তিক হেলথ ট্রেন্ড গ্রাফ এবং ফুল-ফিচার্ড নেটিভ অ্যান্ড্রয়েড অ্যাপ সম্বলিত একটি সম্পূর্ণ স্যুট।

## 📱 অ্যান্ড্রয়েড এপিকে (APK) ইনস্টল করার নিয়ম

এই রিপোজিটরিতে **GitHub Actions CI/CD** স্বয়ংক্রিয়ভাবে সেটআপ করা রয়েছে। আপনি দুটি উপায়ে সরাসরি APK ডাউনলোড করতে পারবেন:

### 🎯 পদ্ধতি ১: GitHub Releases থেকে ইনস্ট্যান্ট ডাউনলোড (সবচেয়ে সহজ)
1. এই গিটহাব রিপোজিটরির ডানপাশের **[Releases](https://github.com/rsk934128-dot)** সেকশনে যান।
2. সর্বশেষ রিলিজ (যেমন: `v1.0.0`)-এ ক্লিক করুন।
3. **Assets** সেকশনের ভেতর থেকে **`NoorLink-v1.0.0.apk`** ফাইলটি সরাসরি আপনার ফোনে ডাউনলোড করে ইনস্টল করে নিন।

### ⚙️ পদ্ধতি ২: GitHub Actions আর্টিক্টস থেকে ডাউনলোড
1. রিপোজিটরির **"Actions"** ট্যাবে প্রবেশ করুন।
2. বাঁপাশের তালিকা থেকে **"Build & Release Android APK"** সিলেক্ট করুন।
3. **"Run workflow"** বাটনে ক্লিক করুন (অথবা যেকোনো সেশনের উপর ক্লিক করুন)।
4. বিল্ড শেষ হলে পেজের নিচে **"Artifacts"** সেকশন থেকে **`NoorLink-Android-APK`** জিপ ফাইলটি ডাউনলোড করে নিন।

## 🏷️ নতুন ভার্সন রিলিজ করার ধাপ (Release Workflow)

টার্মিনাল থেকে মাত্র ৩টি কমান্ড রান করে আপনি সরাসরি নতুন অ্যান্ড্রয়েড এপিকে রিলিজ তৈরি করতে পারেন:

```bash
# ১. সকল কোড কমিট করুন
git add .
git commit -m "Release v1.0.1: Feature update and security enhancements"

# ২. নতুন রিলিজ ট্যাগ তৈরি করুন
git tag v1.0.1

# ৩. গিটহাবে পুশ করুন (অটোমেটিক বিল্ড শুরু হবে)
git push origin main
git push origin v1.0.1
```
> 💡 *ট্যাগ পুশ হওয়ামাত্রই GitHub Actions ক্লাউড রানারে গ্রেডল বিল্ড সম্পন্ন করে নতুন এপিকে ফাইল তৈরি করে স্বয়ংক্রিয়ভাবে রিলিজ পেজে যুক্ত করে দেবে।*

## 💻 লোকাল মেশিনে রান করার নিয়ম (Getting Started)

### ১. সার্ভার ও ওয়েব ড্যাশবোর্ড চালু করা

```bash
# ডিপেন্ডেন্সি ইনস্টল করুন
npm install

# সার্ভার ও PWA চালু করুন (Default Port: 8088)
npm start
```
ব্রাউজারে ভিজিট করুন: **`http://localhost:8088/`**

### ২. অ্যান্ড্রয়েড অ্যাপ কম্পাইল ও রান করা

```bash
# লোকাল ইউনিট টেস্ট যাচাই করুন
gradle :app:testDebugUnitTest

# ডিবাগ এপিকে তৈরি করুন
gradle :app:assembleDebug
```
তৈরি হওয়া এপিকে পাওয়া যাবে: `app/build/outputs/apk/debug/app-debug.apk`

## 🛡️ সিকিউরিটি ও হ্যান্ডশেক প্রোটোকল (Handshake Protocol)

১. **Hello বার্তা প্রেরণ**:
```json
{
  "type": "hello",
  "deviceId": "DEVICE_ANDROID_01",
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "capabilities": ["telemetry", "relay", "ping"]
}
```

২. **সার্ভার ভ্যালিডেশন (`auth.js`)**:
- টোকেনের মেয়াদ ও HMAC-SHA256 সিগনেচার যাচাই।
- টোকেনে উল্লেখিত `deviceId`-এর সাথে রিকোয়েস্টের ডিভাইস আইডি ম্যাচিং।

৩. **নিরাপদ রেসপন্স**:
- যাচাই সফল হলে সার্ভার নোডটিকে রেজিস্ট্রিভুক্ত করে `welcome` মেসেজ পাঠায়।
- অনুমোদন ব্যর্থ হলে তাৎক্ষণিক সংযোগ বিচ্ছিন্ন করে সার্ভার লগে অডিট ট্রেইল সংরক্ষণ করা হয়:
  ```text
  [AUTH_FAILURE] [2026-11-06T07:00:00.000Z] Device: SENSOR_X Code: INVALID_TOKEN Reason: Signature verification failed Client IP: ::1
  ```
